# CS2 Discord Presence

[English version](README.md)

Показывает в Discord **реальную информацию о матче Counter-Strike 2**: карту, режим, текущий раунд, счёт, вашу сторону (CT/T) и K/A/D, а не просто «Играет в Counter-Strike 2».

```
Играет в Counter-Strike 2
Mirage • Соревновательный
Раунд 7 • CT 4:2 • K/A/D 5/1/3
```

## Как это работает

В CS2 есть официальная функция **Game State Integration (GSI)**: игра сама отправляет данные о матче в формате JSON на локальный адрес. Программа слушает `127.0.0.1:3000`, читает эти данные и выставляет их как Rich Presence через локальный клиент Discord.

- Файлы игры не изменяются, в процесс игры ничего не внедряется.
- GSI — официальная функция Valve, поэтому использование **безопасно для VAC**.
- Всё работает на вашем ПК, в Discord уходит только текст статуса.

## Быстрый старт

1. Скачайте `CS2Presence.exe` на странице [Releases](../../releases).
2. Запустите при открытом **десктопном Discord**. Программа сама найдёт папку CS2 и установит `gamestate_integration_discord.cfg`.
3. **Перезапустите CS2** (конфиг читается только при запуске игры).
4. Зайдите в матч, статус обновится автоматически.

В Discord должно быть включено: *Настройки → Конфиденциальность активности → Показывать текущую активность*.

Если папка CS2 не найдена, скопируйте `gamestate_integration_discord.cfg` (появится рядом с exe) в:
`...\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\`

## Своё приложение Discord (по желанию)

1. Откройте <https://discord.com/developers/applications> → **New Application**, назовите `Counter-Strike 2` (это имя показывается в статусе).
2. Скопируйте **Application ID**.
3. Передайте его аргументом (`CS2Presence.exe 123456789012345678`) или положите в `appid.txt` рядом с exe.
4. *(По желанию)* В **Rich Presence → Art Assets** загрузите картинки с именами `cs2`, `de_mirage`, `de_dust2`, `de_inferno`, `de_ancient`, `de_nuke`, `de_anubis`, `de_vertigo`, `de_overpass` и т.д. Картинка карты выбирается по её названию.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) на Windows.

```
build.bat
```

Результат: `dist/CS2Presence.exe`. Если создать тег вида `v1.0.0`, GitHub Actions сам соберёт exe и приложит его к релизу.

## Если не работает

| Симптом | Решение |
|---|---|
| В консоли `[Discord] Не удалось подключиться` | Запустите **десктопный** Discord (не браузерный); оба приложения должны быть запущены с одинаковыми правами. |
| Статус «Жду данные от CS2» не меняется | Перезапустите CS2 после установки конфига; проверьте, что `.cfg` лежит в `game\csgo\cfg`. |
| Пустые запросы в консоли | Это нормально в главном меню; данные придут, когда вы на карте. |
| У карты нет картинки | Загрузите арт с точным именем карты (например `de_mirage`). |
| Порт 3000 занят | Измените `Port` в `Program.cs` и пересоберите. |
